# Демо-сайт городских перевозок

Демонстрационный сайт для городских грузоперевозчиков: перевозка грузов, переезды и услуги грузчиков. Адаптивная главная страница и технические страницы; формы и контакты работают в демонстрационном режиме.

Городские версии: [Брест](https://perevozki-demo.vercel.app/) и [Москва](https://perevozki-demo.vercel.app/moscow/). Общие стили и изображения сохраняются; московские страницы и контроллеры телефона генерируются из исходных файлов командой `node build-city-pages.mjs`, которая также запускается при публикации. Редактировать исходные страницы и конфигурацию генератора, затем пересобирать; содержимое `moscow/` вручную не редактировать. `moscow/badge.png` — отдельное изображение превью ссылки.
