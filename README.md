# Демо-сайт городских перевозок

Демонстрационный сайт для городских грузоперевозчиков: перевозка грузов, переезды и услуги грузчиков. Адаптивная главная страница и технические страницы; формы и контакты работают в демонстрационном режиме.

Городские версии: [Брест](https://perevozki-demo.vercel.app/), [Минск](https://perevozki-demo.vercel.app/minsk/) и [Москва](https://perevozki-demo.vercel.app/moscow/). Общие стили и изображения сохраняются; городские страницы и контроллеры генерируются из брестских исходников командой `node build-city-pages.mjs`. Генератор запускается отдельно при согласованном обновлении городов; публикация выкладывает сохранённые файлы без пересборки, чтобы можно было дорабатывать основную версию отдельно. Изменения общих стилей при этом нужно ограничивать основной страницей. Редактировать исходные страницы и конфигурацию генератора, затем пересобирать; содержимое городских папок вручную не редактировать. Каждая папка содержит отдельный `badge.png` для превью ссылки. Минск сохраняет брестские тарифы и белорусские контакты/маску, Москва использует согласованные российские данные.
